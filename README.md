# Gym Membership Management System

A desktop GUI application built with **Python (Tkinter)** and **MySQL** for managing gym members, subscription plans, payments, and automated renewal reminders.

---

## 🚀 Features

* **Member Management:** Register, view, update, and delete gym members.
* **Subscription Plans:** Create and manage custom membership plans (e.g., Monthly, Quarterly, Annual).
* **Payment Tracking:** Record member transactions and view complete payment histories.
* **Automated Renewal Reminders:** Auto-calculates subscription expiry dates and categorizes memberships into color-coded statuses (**ACTIVE**, **DUE SOON**, **OVERDUE**).
* **User-Friendly UI:** Modern styled tabs, custom headers, and color-coded table rows for clear visual tracking.

---

## 🛠️ Tech Stack

* **Language:** Python 3
* **GUI Framework:** `tkinter` & `tkinter.ttk`
* **Database:** MySQL
* **Database Driver:** `mysql-connector-python`
